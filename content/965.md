We had Joonas Lehtinen, found of Vaadin, give a presentation and lab on the Vaadin framework. For those of you who have no experience with Vaadin, it is a framework for building modern web applications and has a great selection of controls and widgets with expert design.

In this virtual workshop you will learn to build single page web apps in pure Java. While we start from the basics of Vaadin Framework, we should end up with a full stack application based on Java 8, CDI, JPA and HTML5 - using Vaadin 7.2 to glue it all together. We'll continue by spicing up the app with a bit of (S)CSS with a bit of help from the built-in responsive layout extension.
